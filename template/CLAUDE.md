# Job agent rules

This directory is a single, isolated document-to-video job. Stay inside it. The server writes `job.json`, `source/original.<ext>`, `source/text.txt`, and optionally `source/pages/page-001.png` onward. The storyboard agent writes `storyboard.json`; scene agents write `web/scenes/<sceneId>.js`. The director runs `narrate.py` (audio in `build/audio`, choices in `build/narration.json`), `timing.py` (`web/timing.js`, `build/timing.json`), `music.py` (beds in `build/music`), `render.mjs` (video in `build/video`), and `assemble.py` (`out/video.mp4`, `out/video.srt`).

Read `STORYBOARD_SCHEMA.md`, `STYLE.md`, `KIT.md`, and `AGENT_BRIEF.md` as needed for your assigned stage. Narration must state only what the document supports. Do not invent procedures, numbers or regulations. Scene `build(ctx)` creates nodes once; `render(t, ctx, state)` must be a pure function of time. No `Math.random`, `Date`, `requestAnimationFrame`, CSS animation or transitions, SMIL, or accumulating state. Text is at least 22 px, important content stays within 80 px margins, and every `onscreen_text` item is spelled exactly. Time animation with `ctx.beat` and `ctx.cue`; `ctx.cue` throws if a phrase is missing.

Allowed commands: `node tools/validate-storyboard.mjs`, `node nancheck.mjs <sceneId>`, `node render.mjs <sceneId> --draft`, and `node shoot.mjs "scene=<sceneId>" <beatIds> --sheet`. You may inspect files and use local image viewers. Do not run `narrate.py`, `music.py`, or `assemble.py`; do not make network calls or access anything outside this job directory. The director runs paid and full-pipeline stages after your work.
